Site plan: City Explorer Guayaquil

Purpose

Provide curated recommendations for food, parks, and culture in Guayaquil, with mobile-first performance and accessibility.

Audience

Locals and travelers seeking quick, reliable picks with concise info and maps/links.

Content and pages

  • Home: Value proposition, hero, newsletter form.
  • Explore: Dynamic cards powered by JavaScript, filters, favorites.
  • Contact: Accessible form to submit recommendations.
  • References: Source citations (unstyled).

Design and branding

  • Typography: Manrope from Google Fonts for modern readability.
  • Color: Neutral light/dark themes with sufficient contrast checked via DevTools.
  • Layout: Mobile-first single-column, progressive enhancement to grid for desktop. Respect PARC principles.

Accessibility

  • Semantics: Proper landmarks (header, nav, main, footer).
  • Focusable controls: Visible focus, ARIA where appropriate, labels linked to inputs, live regions for feedback.
  • Contrast: Verified via CSS Overview and Lighthouse.

Performance

  • Optimized images: Appropriately sized and compressed with loading="lazy" and <picture> for hero.
  • Minimal JS/CSS: Deferred JS, single CSS file.

JavaScript requirements coverage

  • Functions: Multiple helper and event handler functions.
  • DOM interaction: Select, modify, add event listeners.
  • Conditionals: Theme toggle, filters, form validation branches.
  • Objects/arrays/methods: Places array of objects; uses map, filter, sort.
  • Template literals: All card and message rendering.
  • localStorage: Persist theme, favorites, newsletter/contact confirmations.
